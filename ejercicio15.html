Ejercicio Guiado 15: Ejercicio Guiado de Buckets Simple

1. Introducción

En el desarrollo de aplicaciones modernas, el almacenamiento de archivos estáticos (imágenes, documentos, vídeos) no debe realizarse en el sistema de archivos del servidor, ya que esto dificulta el escalado horizontal.

En este ejercicio, implementamos un microservicio "standalone" utilizando Flask y Google Cloud Platform (GCP). El objetivo es desacoplar el almacenamiento: las imágenes se guardan en un Bucket de Objetos en la nube, mientras que la base de datos relacional (MySQL) solo almacena la referencia (URL pública) y los metadatos.

2. Objetivos del Ejercicio

  • Aprovisionamiento Cloud: Configurar un Bucket en Google Cloud Storage y generar las credenciales de servicio (Service Account) con permisos de escritura.
  • Integración de SDK: Implementar la librería google-cloud-storage en Python para comunicar el backend con la nube.
  • Persistencia Híbrida: Lograr que una sola transacción guarde el archivo en la nube y su registro correspondiente en la base de datos local.

Fase 3: Código del Microservicio (app.py)

El núcleo del ejercicio es el archivo app.py. Utiliza la librería python-dotenv para cargar las variables de entorno sensibles. A continuación se muestra el fragmento clave donde ocurre la "magia" de la subida al bucket: 

# Fragmento de app.py - Lógica de Subida
@app.route('/upload', methods=['POST'])
def upload_file():
    if 'image' not in request.files:
        return jsonify({'error': 'No file part'}), 400
    
    file = request.files['image']
    
    # 1. Conexión al Bucket de GCP
    client = storage.Client.from_service_account_json(GOOGLE_APPLICATION_CREDENTIALS)
    bucket = client.get_bucket(BUCKET_NAME)
    
    # 2. Subida del archivo (Blob)
    blob = bucket.blob(file.filename)
    blob.upload_from_file(file)
    
    # 3. Guardado de referencia en MySQL
    cursor.execute("INSERT INTO images (image_url) VALUES (%s)", (blob.public_url,))
    db.commit()
    
    return jsonify({'message': 'File uploaded successfully', 'url': blob.public_url}), 201

5. Conclusiones

Este ejercicio demuestra cómo externalizar el almacenamiento de archivos en una arquitectura de microservicios. Utilizar Buckets (GCP S3) en lugar de carpetas locales ofrece ventajas críticas: escalabilidad infinita (no se llena el disco del servidor), seguridad (URLs firmadas o públicas controladas) y rendimiento (los archivos se sirven directamente desde la infraestructura de Google, reduciendo la carga en nuestro backend Flask).
